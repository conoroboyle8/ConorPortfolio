IMPORTANT NOTES
---------------
- Demo images are NOT included in this download.
  Sources used in the demo: Unsplash, Pexels.

- AJAX page transitions require a web server to run locally.
  Opening index.html directly from a folder will NOT work.
  Use one of the following:
    - Live Server (VS Code extension) — recommended
    - MAMP / WAMP / XAMPP
    - Any live hosting — works out of the box


QUICK START
-----------
1. Open the /html folder
2. Start a local server (see above)
3. Open index.html in your browser
4. Edit css/variables.css to change colors and fonts
5. Replace placeholder images with your own
6. Upload to your hosting when ready

AI-ASSISTED DEVELOPMENT
-----------------------
agent.md is a structured context file for AI code editors.
Load it in Cursor, GitHub Copilot, Claude, or any AI editor
before asking for customizations.

Your AI will understand the full structure of Hayler —
all CSS variables, components, data-attributes, and patterns —
without you having to explain anything.


CUSTOMIZATION
-------------
Start with css/variables.css — all colors, fonts,
spacing, and cursor settings are defined there.

For adding new pages, use blank.html as your starting point.

Full guide in the documentation.
